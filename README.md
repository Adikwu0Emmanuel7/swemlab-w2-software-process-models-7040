# 🚀 SWEMLAB: Software Process Models: Scenario Analysis

## Week 2 Activity

This lab activity guides students through analyzing a software project scenario to understand and apply various software life cycle models. Students will identify appropriate models, map project phases to the generic process framework, and justify their choices, concluding with a handwritten report.
